01 About

Building for the web — from the first pixel to the final deploy.

I’m a web developer, with an MSc in Computing underway at the University of Huddersfield and a B.E. in Computer Engineering from MBIT.

I work across the stack — hand-written HTML, CSS and JavaScript on the front end, and Python, Django or PHP on the server. From internships building a Travel Agency Booking System and a Library Management System to personal projects shipped and deployed, I take an idea from interface to server logic to database to release.

I care about clean, readable code, responsive design and the small details that make a page feel considered. I’m currently based in Caterham, England, and always building something new.

  1. i.

    Start from the layout

    Responsive by default: every build starts with a structure that works from phone to desktop.

  2. ii.

    Keep the code readable

    Semantic HTML and organised CSS, so the next person to open the file knows exactly what is going on.

  3. iii.

    Ship and iterate

    Deploy early, test on real devices and refine the details that users actually notice.
